# Learning Hub - Log

Append-only chronological record of ingests, refines, lint passes, and quizzes.

Format: `## [YYYY-MM-DD] {{ingest|refine|lint|quiz}} | {{topic}} - {{one-line summary}}`

`scripts/file-blueprint.sh` appends here for you. Write the narrative line by
hand if you want the entry to say something the commit message does not.
